## **咪咕视频能打开，但直播为什么还是不够流畅？**

很多人判断网络好不好，习惯先看下载速度。

家里300Mbps、500Mbps甚至千兆宽带，看起来应该完全能够满足高清视频需求。但实际使用中，仍然可能出现“测速很快，直播却不稳定”的情况。

这是因为视频直播体验并不完全取决于最高下载速度。

尤其是人在海外时，还需要考虑几个因素：

**连接距离**

海外连接国内应用需要经过更长的数据传输路径，网络响应时间自然与本地使用存在差异。

**线路波动**

网络速度并不是始终固定不变的。短时间的大幅变化，很容易影响直播连续性。

**高峰期拥堵**

晚上和周末是网络使用比较集中的时间，也是很多体育比赛的热门观看时段。

**本地Wi-Fi**

路由器距离太远、多人共享网络或者无线信号干扰，同样会影响最终画面。

所以，看咪咕体育直播时，与其只关注“最高能跑多少Mbps”，不如同时观察网络能不能在一两个小时内保持稳定。

**先做个简单判断：到底该优化哪一段网络？**

遇到咪咕视频卡顿，可以通过其他应用的表现快速判断。

| **网络现象** | **优先排查方向** |
| --- | --- |
| 所有网页和视频都慢 | 家庭宽带、Wi-Fi |
| 只有某一台设备慢 | 设备网络状态 |
| 晚上明显比白天慢 | 高峰期网络负载 |
| 海外应用正常，国内应用波动明显 | 跨境连接线路 |
| 咪咕与国服游戏同时不稳定 | 回国网络质量 |
| 高清容易缓冲、普通画质正常 | 带宽占用与线路稳定性 |

如果问题主要集中在本地网络，那么先改善Wi-Fi更加重要。

如果本地上网一直很快，而国内影音、音乐和游戏连接表现明显不同，则可以进一步考虑使用回国网络加速方案。
