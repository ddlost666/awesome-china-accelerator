## “更新后出问题”是一条线索，还不是原因

更新完成前后，游戏文件、后台任务、客户端状态和网络使用情况都可能发生变化。问题恰好出现在更新之后，并不能直接认定是新版本故障，也不能立刻认定电脑配置不够。

最有用的描述是：“下载已经完成，能进大厅，选完英雄后加载失败。”它能把问题缩小到具体阶段。只说“更新完很卡”，往往要来回补充很多信息。

## 先让更新真正结束，再安排开黑

看到登录按钮出现，可以再留意下载、安装或修复任务是否仍在运行。游戏更新之外，系统、其他游戏和云盘也可能同时下载文件。把当前更新完成，暂停不急的后台同步，再开始对局，能减少本地资源被争用的情况。

如果客户端明确提示文件异常，按国服当前提供的官方修复指引操作。Riot 官方的更新问题说明也将更新报错与文件修复列为处理方向；其工具与界面针对对应客户端，国服操作入口应以腾讯当前指引为准。[查看官方更新问题说明](https://support.riotgames.com/en-us/league-of-legends/client/patching-issues)。

不要照着不明教程删除整片文件夹。先保留错误文字、发生阶段和必要截图，能帮助客服判断是否需要修复或重新安装。

## 能进游戏之后，观察画面和操作反馈

更新成功、能进入对局，接下来才是实际游玩表现。画面变成断续的几帧，和角色移动指令迟迟没有反馈，处理方向不同。

FPS表示每秒渲染的帧数，网络延迟通常以毫秒（ms）表示。比如，FPS从100降到30，属于画面输出发生了明显变化；延迟从100ms跳到250ms，则提示连接响应变慢。这里的数字仅用于解释两种指标，不是实测结果或体验承诺。

画面掉帧时，可以查看更新后设置是否符合自己的电脑情况，关闭不必要的后台程序，并关注散热与负载。操作反馈慢、人物回弹或连接中断时，则继续检查本地网络与回国连接。也可能两种情况同时存在，按症状逐项处理即可。
