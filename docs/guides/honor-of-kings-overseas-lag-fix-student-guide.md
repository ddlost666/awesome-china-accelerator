## 先判断：你的延迟属于哪一种？

遇到卡顿时，不要急着更换设备或者修改大量设置。

先简单判断自己的情况。

## 情况一：游戏进不去

表现：

● 登录等待时间长；

● 加载页面卡住；

● 进入大厅失败。

可能原因：

● 网络连接不稳定；

● 游戏登录过程响应慢；

● 当前网络环境不适合连接国服。

## 情况二：大厅正常，但进入比赛慢

表现：

● 匹配等待时间长；

● 加载英雄界面卡顿；

● 进入地图速度慢。

这种情况通常和：

● 网络波动；

● 数据传输不稳定；

● 丢包情况；

有关。

## 情况三：能正常进入游戏，但延迟很高

表现：

● Ping长期200ms以上；

● 技能释放有延迟；

● 团战操作不流畅。

这种就是典型的海外连接国服延迟问题。

## 海外王者荣耀延迟高，主要受哪些因素影响？

很多玩家认为：

“升级1000M宽带是不是就能降低延迟？”

其实不一定。

游戏延迟主要受到以下因素影响：

| 影响因素 | 对游戏体验的影响 |
| --- | --- |
| 玩家所在地 | 距离国内服务器越远，基础延迟越高 |
| 网络线路 | 影响数据传输稳定性 |
| Wi-Fi环境 | 可能造成波动 |
| 高峰时间 | 网络压力增加 |
| 后台程序 | 占用网络资源 |
| 服务器距离 | 决定响应速度 |

简单来说：

下载速度影响“下载文件快不快”。

而Ping值影响“游戏操作快不快”。

两者关注点不同。
