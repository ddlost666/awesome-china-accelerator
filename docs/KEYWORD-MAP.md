## 写作规则

1. 一个搜索意图只保留一个主页面，标题不得与现有文章重复。
2. 支撑页面的标题应体现独立问题，例如设备、平台、错误提示或排查阶段。
3. 支撑页面应在前两节内链接到主页面，主页面可在“延伸阅读”中反向链接。
4. 如果新稿与现有页面的核心答案重合，应更新现有页面，而不是创建新文件。
5. 合并文章后删除重复文件，并同步更新 `README.md`、`docs/README.md` 和 `llms.txt`。
