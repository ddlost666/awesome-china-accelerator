## 二、海外看体育直播，重点不是单纯提高网速

不少用户遇到直播卡顿后的第一反应，是升级家庭宽带。

实际上，如果普通海外网站、视频和游戏下载速度都正常，只有连接国内应用时表现不够稳定，那么问题往往不完全在本地带宽。

海外设备连接国内网络服务时，需要经过更长的数据传输路径。距离增加以后，网络延迟以及线路波动也可能随之增加。

特别是体育直播，需要连续、稳定地接收数据。

因此，比起单纯追求更高的下载速度，降低网络波动、优化连接路径、提高数据传输稳定性往往更加重要。
