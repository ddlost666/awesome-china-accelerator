## 换设备之后，三个状态要重新确认

**账号是否一致。** 手机可能登录了常用账号，电脑却是另一个账号或未登录状态。页面出现会员、购买或登录要求时，先按平台说明处理。

**歌曲是否相同。** 同名歌曲可能存在不同演唱版本。分享原歌曲链接，在另一台设备打开，比重新搜索更容易确认对象。

**连接是否已经建立。** 手机打开加速器，不代表电脑也在使用相同连接。两端的客户端状态需要分别确认；使用路由器方案时，也要按实际配置判断覆盖范围。

这些条件对齐后，若仍有地区提示，可以进一步处理回国连接；若只有单首歌曲持续异常，保留链接咨询音乐平台。加速器不能恢复失效内容，也不能替代平台会员权益。
