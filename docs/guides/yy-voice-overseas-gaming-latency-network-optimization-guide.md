# 海外用YY语音开黑总是卡？海外玩家语音延迟与回国网络优化攻略

## 人在海外，YY能登录，不代表开黑就一定顺

不少海外玩家第一次碰到YY卡顿时，会觉得有点奇怪。

网页能正常打开，视频也能看，游戏下载速度甚至还挺快，为什么一到YY语音里就开始不舒服？

最常见的体验其实不是彻底用不了，而是那种“小问题不断”。

比如朋友已经喊了一句“左边来人”，你这边隔了一下才听见；几个人同时讲话的时候，声音突然变得断断续续；自己明明一直在说，队友却问：

“你麦是不是又卡了？”

这种情况在玩需要频繁交流的国服游戏时尤其影响体验。

平时闲聊慢一点可能无所谓，但《和平精英》《王者荣耀》《三角洲行动》这一类游戏里，很多信息就是几秒钟的事。

报点来晚了，再清楚也没什么用了。

## 海外YY卡，不一定是你的宽带速度不够

很多人的第一反应是测速。

看到家里有300Mbps、500Mbps，甚至更高的宽带，就觉得网络应该没有问题。

其实对于YY这种实时语音应用来说，单看下载速度参考价值并没有想象中那么大。

举个很简单的例子。

下载一部电影的时候，中途网络偶尔抖一下，软件可以继续缓冲，你甚至感觉不到。

但语音交流不一样。

声音需要连续传过去。

一旦网络路径出现明显波动，耳朵马上就能听出来：

声音断了；

一句话缺几个字；

突然出现杂音；

队友讲话明显晚了一拍。

所以海外使用YY时，比“网速到底有多快”更值得关注的是网络稳定性和传输延迟。

尤其你的设备人在海外，而平时联系的朋友、国服游戏以及常用国内应用主要在国内，两边的数据传输距离本身就比较长。

## 为什么白天正常，晚上开黑反而容易卡？

这个现象其实很典型。

下午和朋友聊天没什么问题，一到晚上大家上线，YY开始断断续续。

先别急着怀疑电脑。

晚间本身就是家庭网络使用比较集中的时间。

室友可能在看高清视频，手机正在同步相册，电脑后台还挂着游戏下载，电视上又有人追剧。

这些设备一起跑，本地网络压力自然会增加。

与此同时，海外连接国内网络时，不同时间段的线路状态也可能发生变化。

最后表现出来的结果就是：

白天感觉一切正常，到了晚上，游戏延迟、YY语音和国内影音应用一起开始出现波动。

所以遇到这类问题，建议先做一个很简单的测试。

把暂时不用的下载、云同步和视频播放停掉，再重新进入YY频道聊几分钟。

如果明显变好了，说明本地网络占用就是原因之一。

如果依然没有改善，再继续看海外到国内这段网络。

## 游戏已经很顺，YY怎么还是慢半拍？

这也是海外玩家比较容易碰到的一种情况。

游戏里人物移动很正常，延迟也不算高，可YY里面朋友讲话还是感觉不够同步。

原因在于，游戏和YY虽然同时联网，但它们并不是完全相同的网络使用场景。

只关注游戏状态，并不能代表语音通信也处于理想状态。

所以平时习惯一边玩国服、一边开YY的玩家，更适合把这两个需求放在一起测试。

真正的测试方法也很简单。

不要只打开游戏登录界面看一下延迟。

进入YY频道以后，让朋友正常聊天，然后直接打一局自己平时玩的游戏。

对局过程中留意三个地方：

队友讲话有没有明显延后；

多人同时说话时会不会声音断掉；

团战或者激烈交火时，游戏和YY是否会同时出现波动。

这种测试比盯着一个数字看半天更实际。

## 电脑YY卡，但手机YY正常，先别急着折腾线路

还有一种情况，经常会被误判成网络问题。

同一个房间、同一个Wi-Fi：

手机上YY挺正常；

电脑上却一直不稳定。

这种时候更应该先看电脑环境。

尤其很多游戏玩家的电脑后台程序非常多。

游戏平台在自动更新；

浏览器开着十几个页面；

网盘正在同步；

系统后台还有其他程序传输数据。

这些东西平时可能没什么感觉，但游戏和YY同时运行以后，就可能放大网络波动。

耳机和麦克风也建议顺手检查一下。

有些电脑同时接着蓝牙耳机、USB耳麦、显示器音频设备，Windows偶尔会重新选择输入或者输出设备。

如果YY突然没有声音，先看看设备设置。

别一上来就把软件重新安装一遍。

很多时候只是选错了麦克风。
