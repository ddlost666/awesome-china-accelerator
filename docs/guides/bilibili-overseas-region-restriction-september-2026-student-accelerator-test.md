## 为什么会这样?说人话版原理

两件事儿:

**距离。** 从北美到大陆,光缆绕地球大半圈,基础延迟动辄 200ms+。物理距离摆在这,直连根本没法流畅播放。

**识别。** 国内一些平台对来源 IP 做识别,非大陆 IP 直接拒绝,或者切到大陆 IP 后还会查"这个 IP 干不干净"。公网上很多 IP 段被滥用,平台标记后照样限速。

所以真正能解决海外访问国内 APP 的工具,得同时做好两件事:**走专用回国线路 + 把延迟降到能流畅播放**。
