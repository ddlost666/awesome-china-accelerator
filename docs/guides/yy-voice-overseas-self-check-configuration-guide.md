## 三、按你的设备类型走配置

### A. 只有 PC(Windows 单机)

**前置清单**

● 确认 Windows 系统版本 ≥ Win 10;

● 准备一个国内手机号用于 YY / HiCN 注册。

**配置 3 步走**

1. **装 HiCN 客户端**——到 [安卓客户端二维码](https://www.hicn01.com/) 下载 Windows 版,手机号注册,新用户可领 3–7 天免费试用;

2. **启动加速**——客户端选"游戏模式",节点列表选与你所在地区匹配的回国节点(美西玩家首选 LA),点"启动加速";

3. **开 YY 进房**——等 3–5 秒看到"已连接"且 ping 稳定后,启动 YY,进入目标游戏语音房间。

**自检判定**:如果 YY 语音延迟稳定 <200ms、丢包 <1%,即视为配置成功。

### B. 主要用手机 / 平板(iOS 或 Android)

**前置清单**

● iOS 用户:App Store 区域可切换到中国大陆(用于搜 YY),或准备一台 Android 设备做替代;

● Android 用户:允许安装第三方 APK 即可。

**iOS 配置 3 步走**

1. 在 App Store 搜 HiCN,搜不到时切换中国大陆 Apple ID 重新搜索并安装;

2. 启动 HiCN,授予 VPN 配置权限,选"游戏模式" + 回国节点,启动加速;

3. 同样切换中国大陆 Apple ID 搜 YY 下载,启动 YY 进房测试。

**Android 配置 3 步走**

1. 官网下载 HiCN APK 安装,或在 Google Play 搜 HiCN;

2. 启动 HiCN 授予 VPN 权限,选"游戏模式" + 回国节点,启动加速;

3. 在 Google Play 或官网 APK 装 YY,启动进房。

**自检判定**:在手机 YY 房间里和朋友做 5 分钟对讲测试,如果听感延迟在 1 秒以内、声音连续,配置即视为成功。

### C. 全家多人一起玩(HiCN 路由器方案)

**前置清单**

● 路由器型号支持 HiCN 插件或对应固件(具体型号清单参考 [安卓客户端二维码](https://www.hicn01.com/) 路由器版文档);

● 家庭里所有人愿意统一到同一个回国节点。

**路由器配置 3 步走**

1. 在路由器后台按官方文档刷入 HiCN 加速固件;

2. 登录路由器 HiCN 后台,选"全场景模式" + 回国主节点;

3. 路由器重启后,所有连到这台路由器的设备(PC、手机、电视盒子、智能音箱)都会自动走回国线路,无需每台单独装客户端。

**自检判定**:任意一台设备打开 YY 进房做对讲测试,如果延迟稳定 <200ms,全家设备同步成功。

### D. 短期出差 / 短住(低频使用)

**配置 3 步走**

1. **装客户端**:用你手头的任意一个平台(Windows / iOS / Android)装 HiCN,领取 3–7 天免费试用;

2. **默认配置即可**:节点选你所在国家唯一回国主节点,模式保持默认;

3. **按需订阅**:7 天试用期内如果只用 1–2 次,保留账号即可,后续月付按需开启。

**自检判定**:在出差所在地的一次组排中,如果 YY 延迟稳定 <200ms,即可视为够用。

## 四、决策树:卡在哪一步就走哪条分支

```text
你在哪一步遇到问题?
├─ 客户端装不上
│   ├─ iOS 搜不到 HiCN 或 YY
│   │   → 切换中国大陆 Apple ID 重新搜索
│   ├─ Android 装不上 APK
│   │   → 设置中允许"安装未知来源应用"
│   └─ 路由器找不到对应固件
│       → 在 HiCN 官网查路由器兼容型号清单
│
├─ 启动后 ping 不稳
│   ├─ 晚高峰(20:00–23:00)
│   │   → 同地区主节点 + 同地区备用节点,不要频繁追新节点
│   ├─ ISP 校园网 / 部分欧洲小运营商
│   │   → 联系 HiCN 在线客服,反馈 ISP 与城市
│   └─ 多人车队节点不一致
│       → 全队统一到同一个回国主节点
│
├─ YY 进房后无声音
│   ├─ 听不到自己声音
│   │   → YY 设置里把"语音输入设备"切到耳机麦克风
│   └─ 听不到队友
│       → 重新进入房间一次,让客户端重新建立 UDP 语音通道
│
└─ 试用期到期
    ├─ 高频使用(每周 >2 次)
    │   → 选季付 / 年付,锁定长期单价
    └─ 低频使用
        → 选月付,需要时再开
```

这张决策树贴在桌面或收藏夹,任何一步卡住都能立刻找到下一步。

五项全部打勾,车队就能稳定开黑。

## 七、不同国服游戏 + YY 语音的体感参考

下表是晚高峰时段、HiCN 加速后,不同游戏 + YY 语音的代表性区间(非承诺值,建议自行复测):

| **游戏** | **美国西海岸节点** | **欧洲节点** | **YY 语音体感** |
| --- | --- | --- | --- |
| 《王者荣耀》国服 | 120–150ms | 140–180ms | "说完立刻听到" |
| 《英雄联盟》国服 | 110–145ms | 130–170ms | 团战语音基本同步 |
| 《永劫无间》国服 | 130–170ms | 150–200ms | 招式与语音节拍对齐 |
| 《CS2》国服 / 《无畏契约》国服 | 150–200ms | 170–220ms | 语音可接受;游戏内 ping 单独看 |
| 《和平精英》国服(手游) | 130–170ms | 150–190ms | 语音节拍与脚步声同步 |
| 《原神》国服(多人模式) | 130–180ms | 150–210ms | 语音 + 多人动作同步无感 |

FPS 类游戏(CS2、无畏契约、和平精英)对 ping 极度敏感,游戏内的延迟感受以游戏内 ping 数值为准,YY 语音单独评估。

## 八、订阅档位选择清单

按使用频率对位:

● **每周 > 2 次组排**——选季付或年付,长期单价更划算;

● **每月 2–4 次组排**——选月付,灵活;

● **偶尔用一次**——保留 3–7 天免费试用账号,需要时再开;

● **多人车队 + 全家覆盖**——选年付 + HiCN 路由器版,一次配置长期使用。

具体档位以 [安卓客户端二维码](https://www.hicn01.com/) 当期页面为准。

## 九、按你的设备开始(最小行动清单)

把这一节当 TODO 清单用即可:

● 打开浏览器访问 [安卓客户端二维码](https://www.hicn01.com/),下载对应平台客户端(Windows / iOS / Android / 路由器);

● 与朋友做 5 分钟对讲测试,听感延迟 <1 秒、声音连续即视为成功;

● 在客户端活动页输入 **口令 1124** 免费领取会员加速时长(具体以活动页当时显示为准),结合 3–7 天试用可跑通更完整的场景,再决定订阅档位。
