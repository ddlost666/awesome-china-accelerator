## **场景一：宿舍500M宽带，为什么追剧还是会转圈？**

假设你在海外宿舍使用500Mbps宽带。

晚上回到宿舍，打开爱奇艺准备追两集电视剧。

刚开始播放没有问题，调整到高清画质以后，偶尔开始出现加载；到了晚上网络高峰，情况变得更加明显。

问题可能并不是500Mbps“不够用”。

因为从设备打开视频到最终看到画面，中间大致经历：

**电脑/手机 → Wi-Fi → 当地宽带网络 → 跨境网络链路 → 国内应用**

500Mbps主要代表基础宽带能力，而不能完全代表后面所有网络环节的状态。

只要其中某一段出现明显波动，最终都可能表现为播放器卡顿。

所以海外追剧，除了“速度”，还需要关注**稳定性**。

## **场景二：先用两个测试判断问题在哪**

爱奇艺出现卡顿后，可以先做两个简单测试。

### **测试A：打开平时常用的海外网站**

如果网页、视频、下载全部变慢，那么应该先检查家庭网络。

例如：

路由器信号是否正常；

电脑是否正在后台更新；

室友是否下载大型文件；

手机是否正在进行云端同步。

这些问题没有解决之前，单纯调整其他线路意义并不大。

### **测试B：比较国内应用表现**

如果海外网络一直正常，而爱奇艺、国内音乐以及国服游戏连接表现普遍不够稳定，那么排查重点就可以转向跨境网络。

这种情况下，使用回国加速器进行线路优化更加有针对性。
