## **常见问题**

### **国外玩国服，需要让国内朋友也开HiCN吗？**

朋友按自己的实际网络情况处理即可。海外玩家的跨境路径与国内连接不同，不必照抄彼此的使用方式。

### **用HiCN能跳过任务或联机条件吗？**

不能。游戏内条件由官方规则决定，网络加速不能代替任务进度或改变世界设置要求。

### **联机加载慢，一定是网络吗？**

不一定。设备资源加载、游戏状态和连接都可能影响过程，应结合错误提示及实际表现判断。

### **手机和电脑能一起玩吗？**

应核对游戏当前跨设备规则、账号与目标服务，不要仅凭双方都安装了游戏判断。HiCN支持多种设备，不代表它决定游戏联机规则。

### **为了和朋友联机，需要直接买独享专线吗？**

先看实际需求。HiCN 回国加速器VIP会员与独享专线的游戏延迟表现相同，独享专线更多涉及带宽、设备数量及其他需求，价格与权益以当前客户端为准。

### **新用户3天免费试用怎么安排？**

按当前客户端领取方式开启，选平时约朋友的时间正常使用即可。更换设备不会自动重新获得新用户资格。
