## 玩家说“卡”，背后可能是两回事

近期“无限”的测试讨论很有参考价值。在暴雪社区，有欧洲玩家反映连接延迟、断连；另一则帖子里，玩家明确表示网络延迟正常，困扰主要是低帧率。这些是其他地区测试中的个人反馈，并非国服表现，但提醒了我们：**网络卡顿和电脑掉帧，需要分开处理。**[连接问题讨论](https://eu.forums.blizzard.com/en/wow/t/forever-classic-beta/629331)、[画面性能讨论](https://us.forums.blizzard.com/en/wow/t/beta-runs-awful-on-my-pc/2352925)

以后进入国服，如果画面转动流畅，技能响应、拾取或角色移动却不连贯，可以重点检查网络和服务器状态；如果转动镜头就明显掉帧，则要同时检查画质、散热和后台程序。

别看到一个“卡”字，就急着升级宽带或换电脑。先分清是哪种卡，才好往下处理。

## 回归前，你可能还想问

### 现在开通HiCN，就能进入“无限”国服测试吗？

还需要等待官方开放，并满足游戏参与条件。HiCN提供网络加速，不提供游戏测试资格，也不能替代相应账号权益。

### 为什么推荐先试用，而不是直接选长期套餐？

海外用户所在地区、运营商和家庭网络差异很大。用新人3—7天免费试用，在自己常用的设备与时段观察效果，更容易判断是否适合。只关注“无限”的用户，也应先看试用有效期与开测安排。

### 加速后能保持和国内队友一样的延迟吗？

不能保证。跨境距离始终存在，网络加速更适合用来优化连接路径、改善可处理的波动。关注游戏过程是否更稳定，比追求一个与国内朋友完全相同的数字更实际。

### 开测后还是不顺，找客服时该说些什么？

提供所在国家或地区、运营商、游戏版本、问题发生时段，以及错误提示或延迟截图。如果是帧率下降，也一并说明，方便区分网络与设备问题。
