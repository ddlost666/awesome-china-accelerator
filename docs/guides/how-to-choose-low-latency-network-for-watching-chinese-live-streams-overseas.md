# 海外看直播，卡顿往往来得很“会挑时候”

## 家里网速够快，为什么还是看得不舒服？

这一点确实容易让人误判。

很多海外家庭现在宽带速度并不慢。

500M、1G都不少见。

但一看国内直播，情况就变了。

原因并不复杂。

你本地测速的时候，通常连接的是离自己比较近的网络节点。

可国内直播的数据，需要从国内一路传输到你所在的海外地区。

这中间经过的网络路径更长。

而且并不是每一段都一直保持理想状态。

有时候整体带宽够，但中间某一段延迟开始升高；

有时候数据会绕路；

还有的时候，晚上网络使用人数一多，线路波动就明显起来。

于是就会出现一种挺常见的场面：

测速很好看。

直播还是转圈。

这并不矛盾。

问题不一定出在“网速不够”，而可能出在海外到国内这段网络不够稳。
