## 入会前，把“我应该能来”换成具体时间

最容易产生误会的一句话，是“周末一般都有空”。国内队友理解的周六晚上，可能正好是你当地需要处理家事的时间；你说自己晚上上线，大家也未必知道是哪一个时区。

发入会信息时，可以一次讲清四件事：所在时区、固定可玩的日期、每次能连续玩的时长，以及临时缺席会提前多久说明。不必公开住址，给出当地时间和北京时间即可。遇到当地夏令时切换，再更新一次约定。

时长也值得说清楚。能准点上线、只能待一小时，和能够完整参加整场活动，是两种不同的安排。提前讲明白，组织者才能合理留位置，你也不用每次临时解释。

组队时突然失联，队友不知道你是离开了，还是正在重连。可以在开玩之前约定：发生异常先在群里发消息，由谁联系组织者，等待多久再启用替补。

例如：“我这里连接异常，正在重连；请先按团队安排继续，我恢复后在群里回复。”不用每次长篇解释，也别在没把握时承诺马上回来。
