## 国内朋友不怎么卡，为什么轮到我就跳延迟？

同一局游戏，队友所在地区、使用的运营商和连接路径都可能不同。海外玩家连接国内服务器，需要经过跨境网络；线路拥堵或本地无线信号波动，都可能让体验不稳定。

所以，家里下载速度快，不等于打国服就一定顺。游戏下载看的是数据能多快传完，对局更在意交互是否及时、连续。短时间的波动，也可能打乱一次原本安排好的配合。

先问队友一句“你们也卡吗”，能帮助缩小排查范围：

| **开黑时的情况** | **可以先做的判断** | **建议动作** |
| --- | --- | --- |
| 主要是海外这一端延迟波动 | 重点检查自己的跨境线路与本地网络 | 开启HiCN，对比加速前后的对局表现 |
| 多名队友同时异常 | 可能涉及服务器或共同网络问题 | 查看游戏公告，记录发生时段 |
| 延迟变化不大，画面帧数却明显下降 | 更需要排查电脑性能 | 检查后台负载、画质和散热 |
| 游戏基本正常，语音单独断断续续 | 语音应用连接或设备可能有问题 | 分别检查麦克风、语音应用与网络 |

这张表是排查起点。尤其是语音正常、游戏不正常的时候，别急着认为“网络肯定没问题”，不同应用的连接表现可以不同。

可以试，但也要处理本地连接。尽量接网线，暂停自己设备上的下载；如果宿舍网络本身持续拥堵，回国加速也无法替代本地带宽。把本地连接和回国线路分别检查，更容易找到原因。
