官方近期已经发布“无限”的GPU配置要求，部分较旧图形架构将不再获得支持。使用旧电脑的玩家，先查一下自己的硬件是否符合要求，比等到安装时再着急更好。[官方GPU配置说明](https://wow.blizzard.cn/news/24301512/index.html)
