# 汽水音乐海外党速查清单：8 件事一次做完（2026 实测版）

打开加速器之前、打开加速器之后、退订之前各需要做哪些事？这是一篇速查清单——不写故事、不写原理，直接列条目。每条都对应一个可执行的动作或者一个可观察的指标。

下面这 8 件事可以按顺序做，也可以挑今天用得上的先做。

## **一、3 件事：装机前先想清楚**

1. **盘点设备**：手机 / 平板 / 笔记本 / 智能音箱 / 智能电视 / Android 盒子 / 路由器——一台路由器带全家是省心选项，单独装客户端覆盖单设备更灵活。

2. **盘点所在地区延迟基线**：北美 / 欧洲 / 澳洲 / 日韩 / 东南亚差异巨大，确定自己所在地区能跑通 HiCN 节点后再深度试用。

3. **确认预算区间**：月付灵活、季付适中、年付折算单价最低；试用期结束后不主动订阅不会自动扣费。

## **二、3 件事：装机阶段一次性做完**

1. **Windows 客户端**：从 [安卓客户端二维码](https://www.hicn01.com/) 下载安装包；注册账号；选节点一键连接；勾选「开机自启」「断线自动重连」。

2. **iOS 客户端**：App Store 搜「HiCN」下载；首次启动授予 VPN 配置权限；状态栏会显示「VPN」小图标，不需要时在系统设置中关闭即可。

3. **Android 客户端**：Google Play 安装是推荐路径；APK 安装失败时进「安全与隐私 → 安装未知来源应用」打开开关。

## **三、3 件事：路由器加速一次性配置**

1. **核对型号**：确认路由器型号在 HiCN 支持列表里；

2. **备份固件**：刷固件前务必备份原厂固件；

3. **刷入并登录**：刷入 HiCN 固件后登录账户，选大陆节点——智能音箱、智能电视、Android 盒子自动共享加速通道。

## **四、3 件事：装机后立刻跑的小测试**

1. **延迟测试**：用客户端内延迟指示或第三方工具测一次你所在地区到大陆节点的延迟。

2. **缓冲测试**：连续播放 1 小时歌单，记录缓冲次数（不切换节点、不切歌单）。

3. **曲库测试**：检查热门新歌是否能搜到，付费会员曲库是否解锁完整。

## **五、3 件事：试用期内的「压力测试」**

1. **晚高峰压力测试**：北京时间 20:00-23:00 连续播放 30 分钟。

2. **多设备压力测试**：至少 2 台设备同时在线 24 小时。

3. **跨应用压力测试**：边听汽水音乐边开国服游戏或视频会议，观察双应用并发体验。

## **六、3 件事：试用期结束前的收尾动作**

1. **整理一周数据**：缓冲次数 / 高峰期加载耗时 / 多设备断线次数 / 跨应用并发表现。

2. **走一遍退订流程**：试用期结束前 24 小时主动在账户中心「订阅管理」一键取消，确认不自动扣费。

3. **决定订阅档位**：轻度月付、中等季付、重度年付。

## **七、3 件事：长期使用时的注意事项**

1. **节点定期切换**：固定节点长期使用可能逐渐变慢，每月切到其他城市节点对比一次。

2. **客户端更新**：iOS / Android / Windows 客户端新版本可能带来新协议支持，留意更新提示。

3. **路由器固件更新**：路由器加速固件定期更新，跟官方教程同步。

## **八、3 件事：FAQ 里最常被问到的细节**

1. **曲库还是不全怎么办**：客户端内切换其他城市节点，或检查系统时区是否还显示海外。

2. **iOS 找不到汽水音乐**：HiCN 连接状态下切换到国内 Apple ID 单独下载汽水音乐本体。
