## 先描述“怎么卡”，再决定改哪一部分

| 实际表现 | 先关注什么 | 可以从哪里开始 |
| --- | --- | --- |
| 画面帧数下降，转视角也不顺 | 渲染、后台负载与界面配置 | 减少不必要的后台任务和界面功能 |
| 界面报错，按钮或面板异常 | 插件版本与近期配置变化 | 在安全环境中逐项停用、核对更新 |
| 画面流畅，交互反馈却变慢 | 延迟、本地联网与回国线路 | 查看连接状态，准备游戏加速 |
| 游戏和语音同时断开 | 基础网络是否可用 | 先恢复联网，再检查服务连接 |
| 出现维护或账号提示 | 官方公告与完整错误文字 | 按游戏指引处理 |

FPS表示画面每秒渲染的帧数，网络延迟通常以毫秒表示。帧数下降和延迟升高可能同时出现，不能只凭“团战卡”就认定是某一个原因。
