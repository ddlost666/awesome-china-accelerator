## **家里500M宽带，为什么看国内直播还是会转圈？**

这个问题很多海外用户都会问。

“我家网速已经这么快了，为什么还卡？”

原因是，家庭宽带测速和连接国内直播平台，是两件不同的事情。

测速时，设备通常连接的是距离自己比较近的测试服务器。

例如人在新加坡、洛杉矶、温哥华或者伦敦，测试出来的主要是本地网络表现。

但打开国内直播以后，数据需要经过更长的网络路径传输。

中间经过的线路更多，距离也更远。

只要其中某一段出现拥堵或者明显波动，最终看到的直播就可能开始缓冲。

所以会出现一种看起来很奇怪、实际上很常见的情况：

海外网站加载飞快；

下载速度也很漂亮；

一打开国内直播，体验立刻变差。

这时候继续把500M升级成1G，效果未必有想象中明显。

更应该看的，是海外到国内这一段网络走得稳不稳。

## **“低延迟回国专线”到底应该看什么？**

不少人看到“低延迟”，第一反应就是数字越低越好。

但看直播不能只盯着一个瞬间的延迟数字。

真正值得关注的有三个方面。

### **第一，线路不要大起大落**

假设一条线路刚连接的时候表现特别好，但过几分钟就开始明显波动，那对于直播来说意义并不大。

因为你不可能每看十分钟比赛就重新切一次线路。

真正舒服的是：

开播前连好；

中间不用管；

一直看到结束。

这才是直播场景真正需要的稳定。

### **第二，高清画质能不能持续跑**

有些线路刚打开直播时没什么问题。

一切到高清甚至更高画质，马上开始缓冲。

所以测试回国线路的时候，别只看直播间“能不能打开”。

最好把画质切到自己平时真正会看的档位。

然后连续播放一段时间。

如果高清能够稳定维持，参考价值才比较高。

### **第三，高峰时间表现怎么样**

下午测试很好，不代表晚上也一样。

很多留学生真正看直播的时间，本身就集中在晚上或者周末。

这时候宿舍、合租房和家庭网络里，其他设备也开始大量联网。

有人刷视频；

有人下载游戏；

有人开视频通话；

电视也可能正在播放节目。

所以测试低延迟线路，最好直接挑自己平时最常看直播的时间段。

这种测试才真实。
