## 先分辨网络延迟，别把画面掉帧当成 Ping

如果屏幕画面不流畅，但移动位置和操作反馈正常，先检查显卡负载、画质和后台程序。若画面本身顺畅，角色移动、开火反馈却慢或突然回弹，再看网络状况。

开局前暂停云盘同步、系统更新和大型下载。电脑尽量使用网线；使用 Wi-Fi 时靠近路由器，减少隔墙和远距离连接。多人合租时，室友同时下载或播放高清视频也可能影响本地网络表现。

如果同一时间其他国内应用也变慢，而本地网络信号稳定，可以进一步检查海外到国服的连接路径。单次 Ping 数值只能提供一个参考，连续游玩时是否反复波动，对判断体验更有帮助。
