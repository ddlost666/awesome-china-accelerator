## **第一局顺畅，只能说明当时可以正常玩**

连续开黑期间，电脑温度、后台任务和家庭网络使用情况都可能变化。你开始游戏时没人下载，过一会儿室友打开了视频；你第一局只开游戏，后来又开直播、录屏和一堆浏览器页面。不同变化，处理方向也不同。

| **你看到的表现** | **先看什么** | **可以先做的动作** |
| --- | --- | --- |
| 画面不流畅，团战时尤其明显 | FPS变化、电脑负载与散热 | 关闭不必要的后台程序，适当降低画面设置 |
| 画面流畅，移动和技能反馈变慢 | 延迟变化、本地网络占用 | 暂停下载与同步，检查回国连接 |
| 游戏和语音同时中断 | 本地网络是否断开、其他服务是否正常 | 检查网线或无线连接，恢复网络后再重连 |
| 只有游戏掉线，其他应用仍正常 | 游戏公告、错误提示、当前连接 | 记录提示，分别查看游戏服务与加速状态 |

因此，“越打越卡”本身不能直接证明是某一条线路或电脑硬件出了问题。先回想异常从什么时候开始：进入团战、打开录屏之后，还是到某个时段整个连接都变差？这个线索能帮你少走弯路。

这些现象可能同时出现。先处理最明显的一项，再决定下一步；一次改动很多设置，反而不容易知道哪一步起了作用。

## **卡顿时看两种数字，别把 FPS 当成网速**

FPS描述画面每秒渲染的帧数，延迟通常以毫秒（ms）显示。举个说明用的例子：FPS从120降到30，和延迟从120ms升到300ms，代表的变化不同；这些数值只是帮助理解，不是国服实测结果或体验标准。

画面帧数下降时，先查看电脑性能、后台负载与游戏设置。延迟变高、交互反馈不连贯时，再看连接情况。Riot 官方也将短暂卡顿、持续低帧数和游戏无响应分开处理，说明“卡”需要进一步描述。查看官方卡顿说明。

如果异常出现在连玩几局之后，可以在这一局结束后退出不必要的录屏和直播程序，看看散热口是否被遮挡，再重新安排下一局。暂时不用急着重装游戏。
