## 刚掉线时，先做两个判断

第一，电脑还能不能正常上网？如果语音、网页和游戏同时中断，先看网线、无线连接或住处网络。基础网络没有恢复，反复登录游戏通常也无法继续。

第二，游戏有没有明确错误提示？保留文字或截图，再看是否涉及维护、账号验证或其他服务状态。网页能打开，只能说明部分访问正常，不能据此排除游戏连接问题。

给队友留一句简短说明也有帮助：“我掉线了，正在重连，恢复后告诉大家。”先说明当前状态，不必在没把握时承诺马上回来。

## 看视频正常，不代表游戏路径一定顺畅

游戏需要持续交换交互数据，视频则可以依靠一定缓冲，两者对短时波动的表现不同。暴雪官方技术支持帖也提醒，其他网站能下载或播放，并不能单独代表游戏连接没有问题；占用带宽的活动可能使连接问题加重。[查看暴雪官方技术说明](https://us.forums.blizzard.com/en/wow/t/common-technical-issues-and-solutions/22912?blzcmp=blizzard-news)。

因此，掉线后可以留意后台是否正在上传视频、同步文件或更新其他游戏。合租住处多人同时使用网络，也应结合实际占用判断，不能只凭宽带套餐标称速度下结论。

若画面持续不流畅，转动视角也明显卡顿，则还要查看电脑渲染负载。网络延迟与FPS是不同指标，可能同时异常，需要分别处理。
